# Retired Long-Duration Pilot Procedure

The former V9 controlled-pilot procedure is retired from RF Monitor’s development and release command surface.

- The required qualification ladder is V0–V7.
- No required gate or agent-run task may exceed 24 elapsed hours.
- Production readiness uses live receiver evidence from V5–V7 and does not read a V9 result.
- The packaged `external:v9:controlled-pilot` command is intentionally unavailable.

Historical implementation records remain under `docs/validation-results/` for provenance only. They are not instructions, release blockers, or production evidence.
